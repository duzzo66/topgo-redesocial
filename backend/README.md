# Backend

Ponto de partida para a API do projeto **togo**.

Sugestão de próximos módulos:

- autenticação do casal;
- publicações e curtidas;
- memórias com fotos;
- mensagens privadas;
- linha do tempo do relacionamento.

O frontend atual funciona com dados estáticos e está pronto para consumir endpoints quando a API for criada.
